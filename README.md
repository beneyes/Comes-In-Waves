# Comes In Waves
Ambisonic Installation System 

Load up files in the decks on the left. 

This patch  will require IEM VST plugins loaded in your plugin directory. 
https://plugins.iem.at/
This contains necessary panners, ambisonic effects and the ALLRAD decoders. 
Make sure these are installed before loading the Mac patch. 

The four ambisonic decks on the left will take 16 channel b format files

These files are decoded by the mixer straight into the ambisonic speaker system. 

Press the crosses and turn on audio to activate the max patch 
The fading and selection is generative, the speed of which can be altered by the sliders dotted around the decks. 

The four stereo decks on the right can take stereo or mono files a the and automatically panned. Again the speed of this can be changed using the vertical sliders.

For stereo binaural monitoring load IEM binaural monitor  into the stereo output plugin slot.
